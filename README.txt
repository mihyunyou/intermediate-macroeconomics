교체 방법

1. index.html을 해당 GitHub 저장소 최상위의 index.html과 교체합니다.
2. assets/styles.css를 저장소 assets 폴더의 styles.css와 교체합니다.
3. 기존 PDF 폴더는 그대로 둡니다. 이 압축파일에는 수정된 HTML/CSS만 포함되어 있습니다.
4. GitHub Pages 배포 후 새 상단 메뉴를 눌러 피드백 섹션을 확인합니다.

학생 회고는 검토용으로 포함했습니다. 공개 게시 전 학생들에게 이름 없는 인용에 대한 동의를 받는 것을 권합니다. 시험지 원본과 학생 이름, 성적은 포함하지 않았습니다.
