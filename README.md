# Intermediate Macroeconomics — Teaching Materials

Standalone GitHub Pages archive for ECON 102: Intermediate Macroeconomics (Summer 2022).

## Publish on GitHub Pages

1. Create a public GitHub repository named `intermediate-macroeconomics`.
2. Upload **the contents of this folder** to the repository root. Do not upload the ZIP file itself.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then click **Save**.

The published address will be:

`https://YOUR-USERNAME.github.io/intermediate-macroeconomics/`

Use that address as the course-materials link in Google Sites. PDF files open directly in the browser without showing the GitHub repository interface.

## Updating a PDF

Upload the replacement using the same filename and folder path to preserve the existing public link.
